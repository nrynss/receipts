## A claim. A clip. A call for review.

Receipts lets a viewer save a streamer’s promise with `!receipt`. The service captures transcript evidence and requests a Twitch clip. Later speech can create a private review for the channel owner.

The owner can approve a stamp or open an appeal. Chat can vote on an appeal. The overlay displays the resulting verdict, and `!lore` reports channel history.

Recent fixes improve split promises, review updates and the actionable review queue. Offline checks passed. [Read the verification limits](./evidence/).

## What the live run established

One staged run saved a promise, created a ready Twitch clip, and confirmed capture in chat. A later owner-spoken line produced private reviews after a sentence-matching repair. The owner approved a review, then chat upheld an appeal with one vote.

The paired OBS source displayed the upheld verdict. The final run did not confirm clip playback or its labelled fallback. Restart recovery also needs another hosted observation. [Read the evidence and limits](./evidence/).
