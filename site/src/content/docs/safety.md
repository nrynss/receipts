## Human approval controls public outcomes

Automatic stamps are disabled. A model result creates a private review for the owner. The owner must approve a stamp or open an appeal.

Sensitive and uncertain results fail closed. The service restricts speaker attribution to the broadcaster’s sole-voice source segments. This does not provide unrestricted speaker identification.

## Pause and stop mean different things

The owner can pause stamps while the service continues to listen. Stopping listening ends active capture. A durable void removes a saved claim from future review.

Accounts keep separate channel data. A paired OBS source can read the overlay only. The owner can revoke that source or disconnect Twitch access.

## Hosted limits

The hosted service allows one active channel. Its operator funds model usage within a shared cumulative $20 ceiling. Each channel and session also has a $20 ceiling.

Those limits do not show current remaining capacity. The service can refuse a live session when another channel is active or configured capacity is unavailable. Judges do not need an API key or payment details.

## Known limits

The reviewed evaluation found false positives and does not establish future accuracy. Automatic stamps remain off while the team evaluates the model path.

The latest hosted run still needs confirmation for OBS clip playback or labelled fallback. Hosted restart recovery also needs a new observation. See [evidence details](../evidence/).
